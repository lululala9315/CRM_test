shadcn/ui 채택 — Semantic Sync 전략

UI 컴포넌트는 shadcn/ui (style: radix-vega) 베이스. shadcn 표준 토큰 의미를 보존하면서 Figma 디자인 토큰을 별도 prefix로 노출 → 신규 shadcn 컴포넌트는 수정 거의 없이 그대로 작동.

shadcn 표준          Figma 1:1 노출
───────────          ──────────────
bg-primary           bg-canvas-primary
text-primary         text-content-primary
border-border        border-subtle

검증 3단계만 거치면 끝 — font-bold → font-semibold, rounded-xl → rounded-lg, dark: prefix 제거.

한 눈에 보는 규칙 — Do / Don't

DO — 권장

font-semibold        (weight 600)
rounded-lg           (8px, Vega 상한)
bg-canvas-primary    (흰 카드)
bg-canvas-tertiary   (페이지 배경)
text-content-primary (진한 본문)
border-subtle        (카드 보더 · 가장 多)
bg-primary-subtle    (선택/활성 틴트)
<Button>             (variant default)

DON'T — 금지

font-bold            → font-semibold
rounded-xl           → rounded-lg
dark: prefix         → 라이트 전용
bg-primary/10        → bg-primary-subtle
ring-ring/50         → ring-ring-glow
border-line-subtle   → border-subtle
bg-secondary         → bg-canvas-secondary
text-assistive       → text-content-assistive
